# Proyecto Carrocería

Bienvenido al repositorio principal del sistema de gestión de Carrocería.

Este proyecto está dividido en dos partes principales:
1. **Frontend:** Una aplicación React con TypeScript construida con Vite. (Carpeta `frontend`)
2. **Backend:** Una API REST en Node.js con TypeScript, Express y Prisma. (Carpeta `backend`)

## Comenzar el desarrollo

Para levantar ambos entornos, te recomiendo abrir dos terminales separadas.

### 1. Iniciar el Frontend
```bash
cd frontend
npm install
npm run dev
```

### 2. Iniciar el Backend
```bash
cd backend
npm install
npm run dev
```

## Entorno de GitHub y Codespaces
Para iniciar con GitHub Codespaces (Fase 2 de tu plan):
1. Crea un repositorio vacío en GitHub.
2. Abre la terminal en esta carpeta y ejecuta:
   ```bash
   git add .
   git commit -m "Inicialización del proyecto"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   git push -u origin main
   ```
3. Una vez en GitHub, ve a la pestaña "Code" -> "Codespaces" y haz clic en "Create codespace on main". ¡Tendrás todo listo en segundos!
